Install in Gmail (iPhone / Android)

  1. Tap Copy Email Signature above (or use Select All → long-press → Copy).
  2. Open the Gmail app → tap your profile photo → Gmail settings → choose your account.
  3. Tap Mobile Signature (or Signature) → turn it on if needed.
  4. Long-press the signature field → Paste → save.
  5. Send yourself a test email and confirm the photo, QR, and links look right.

Gmail on iPhone sometimes pastes plain text from the system clipboard. If that happens, paste from a desktop browser once, or use Select All → Copy on this page and paste again.

Install in Gmail (desktop)

  1. Click Copy Email Signature above.
  2. In Gmail on the web: Settings (gear) → See all settings → General.
  3. Scroll to Signature → create or edit a signature → paste (⌘V / Ctrl+V).
  4. Choose that signature for new emails (and replies if you want) → Save Changes.
